# ENTRE NÓS

**Tudo começa com uma conversa.**

MVP 18+ de conexões e relacionamentos.

## Stack
- Next.js App Router
- Supabase
- Vercel

## Rodar
1. Copie `.env.example` para `.env.local` e informe a chave publicável do Supabase.
2. `npm install`
3. `npm run dev`

Nunca coloque `service_role` ou secret key no frontend.
